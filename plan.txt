HMI Redesign for Waveshare ESP32-S3-Touch-LCD-7
Context
The HMI project currently uses SPI-based LCD (ST7789) and a placeholder touch handler, but the actual hardware is a Waveshare ESP32-S3-Touch-LCD-7 with:

RGB parallel display (ST7262, 800x480, 16-bit)
GT911 capacitive touch (I2C)
CH422G I/O expander (backlight on EXIO2, touch reset on EXIO1)
8MB Octal PSRAM for framebuffers
RS485 on GPIO15(TX)/GPIO16(RX)
The user wants: optimized touch controls, trend charts for measured values (24h + 7d), and a premium dark-themed interface.

Control: HSYNC=GPIO46, VSYNC=GPIO3, DE=GPIO5, PCLK=GPIO7
I2C: SDA=GPIO8, SCL=GPIO9, Touch INT=GPIO4
RS485: TX=GPIO15, RX=GPIO16

Phase 2: Data Infrastructure
2.1 Create Trend Data Module
New file: src/hmi/trend_data.h and src/hmi/trend_data.cpp

Circular buffer in PSRAM for pH, ORP, temperature
Two resolutions: 1-minute samples (24h = 1440 points), 15-minute samples (7d = 672 points)
Functions: trend_data_init(), trend_data_add_sample(), trend_data_get_series()

Called from communication.cpp when new system_data arrives
